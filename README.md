# Toonbench

Unity の `.unitypackage` をブラウザで開き、マテリアルを [three-liltoon](https://github.com/mochiya-labs/three-liltoon) で描画する Vite / TypeScript 製のビューアです。Unity Editor での変換やモデルのアップロードは不要です。

## 起動

Node.js 22.12 以降を推奨します。

```sh
npm ci
npm run dev
```

ターミナルに表示された URL を開いて、ファイルをドロップするか「ファイルを開く」で選択します。ファイルはブラウザ内で開きます。モデルや対応する Prefab が複数ある場合は「表示モデル」で切り替えられます。「マテリアル内訳」では元の lilToon 設定を取り込んだものと、別のシェーダーから近似変換したものを区別します。

ドラッグで回転、右ドラッグで平行移動、スクロールでズームできます。ビューポート右下に全体表示と自動回転のボタンがあります。

## アニメーションと揺れ

モデルを開くと、対応する全身クリップがあれば再生します。クリップがない人型モデルでは、骨の配置から腕を下ろした「待機」を作ります。「モーション」で「手を振る」「元のポーズ」へ切り替えられます。再生ボタンで全身・表情・揺れを一緒に一時停止でき、速度は 0.5〜2 倍です。

- **表情**：パッケージの Unity `.anim` から、メッシュのパスとブレンドシェイプ名が一致する曲線を再生します。全身モーションとは別に選べます。まばたき用のシェイプがあるモデルでは、待機時に「自動まばたき」も使えます。クリップ名に手のジェスチャーが付いていても、Unity Humanoid の指の筋肉カーブは適用しません。
- **揺れ**：モデルに含まれる PhysBone の設定から髪・尻尾・スカートなどに三次元のばねを適用します。「揺らす」は横向きの力を加えます。「揺れの強さ」を 0% にすると揺れの補正を解除します。Unity/VRChatと完全に同じ物理結果にはなりません。
- **別のモデル**：FBX・glTF の埋め込みクリップ、テキスト形式の Unity の汎用位置・回転・スケールの対応カーブ、VRM 0.x/1.0 の標準 Spring Bone を読み取ります。汎用カーブは対象の階層とローカル軸が対応する場合に限ります。揺れ設定がなければ髪などのボーン名から対象を推定し、その旨を表示します。

## 読み込みの流れ

1. Web Worker が gzip/tar を展開し、Unity の GUID をキーとして `pathname`・`asset`・`asset.meta` を対応付けます。パッケージ内の C# や Unity シェーダーコードは実行しません。
2. Three.js でモデルを読み、Prefab のレンダラー設定、FBX Importer のマテリアル割り当て、同名のマテリアルの順で各スロットの `.mat` を解決します。名前での照合は候補が一意のときだけ行います。
3. Unity のシェーダー名または既知の lilToon シェーダー GUID を解決し、対応する `LilToonMaterial` を作成します。色、テクスチャとそのタイリング・オフセット、描画キューを渡し、WebGL 2 で輪郭線や透過を描画します。画像は同じパッケージ内から取得します。

主な検証対象は FBX と Unity のテキスト形式のマテリアルです。OBJ、glTF/GLB、VRM のメッシュにもローダーがあり、glTF の `MOCHIYA_materials_liltoon` 拡張を認識します。arktoon / Standard や未解決のマテリアルは共通する設定を使った近似表示になります。

## 対応範囲

- Unity のシーン全体を再現するものではありません。Prefab はモデルとマテリアル割り当て・表示状態の一部を参照します。複数 FBX を参照する場合はモデルごとの表示です。Animator Controller のステートマシン、Unity の Humanoid リターゲットや独自コンポーネントは実行しません。PhysBone などは保存された設定から近似します。
- バイナリ形式の Unity シーン/マテリアルや独自シェーダーの完全な再現には対応していません。外部依存の画像・マテリアルはパッケージに含めてください。Unity Cubemap は未対応です。PNG、JPEG、WebP などのブラウザ対応画像と TGA を読めます。
- FBX のスキンウェイトは Three.js の FBXLoader が頂点ごとに 4 本までに絞ります。「元のポーズ」で FBX の初期姿勢を確認できます。
- 読み込み上限は圧縮時 512 MiB、展開時 768 MiB、1 アセット 256 MiB です。WebGL 2 と DecompressionStream が使用できるブラウザが必要です。

## Cloudflare Workers にデプロイ

```sh
npx wrangler login
npm run deploy
```

複数の Cloudflare アカウントにアクセスできる場合は、対象の `CLOUDFLARE_ACCOUNT_ID` を環境変数に指定してください。`npm run deploy` は本番ビルドを作り、配信ファイルの一覧を検査してから、`dist/` のみを Workers Static Assets としてデプロイします。サイトはモデルを同梱せず、ユーザーが選択したファイルをブラウザ内で処理します。

ローカルの確認用モデルは `ref/`、スクリーンショット・録画は `output/` に置いてください。両方とも Git の対象外です。関連するライセンスは `public/licenses/` にあります。
